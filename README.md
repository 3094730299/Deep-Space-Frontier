# 深空铸造体 · Deep Space Deployer

《我的世界》**1.21.1 + NeoForge** 的**航空学（Create: Aeronautics）附属模组**。
六家星际公司在世界上建厂，玩家在工厂里交易模块、选择蓝图、一键组装并焊接物理结构。

> 当前版本：**0.1.14** —— 四个功能方块 + 银行卡 + 六种票据 + 界面已经能跑；
> 商品、蓝图组装、焊接联动、世界生成在后续版本接入。

---

## 六家公司

| 代号 | 公司 | 方向 |
|---|---|---|
| `threshold` | 阈限实验集团 | 实验/科研 |
| `whisperbelt` | 低语环带科技 | 环带/隐形 |
| `brokenedge` | 断锷军械财团 | 军械/武器 |
| `skimmer` | 掠影推进公司 | 推进/引擎 |
| `bedrock` | 磐基重工工业 | 重工/装甲 |
| `astralink` | 星联动力联盟 | 能源/动力 |

每家公司都有**自己的票据**（货币），**不能通用**，在公司之间兑换要付手续费（汇率可配）。

## 四个功能方块

| 方块 | 作用 | 现在能做什么 |
|---|---|---|
| **工厂终端**（商店） | 插卡开机 → 买卖、兑换、选投放点 | ✅ 插卡开机、存票据、取现、跨公司兑换、账户绑定、**按页选购商品（等级+声望解锁）**、**卖蓝图凭证（物理结构使用权）** |
| **收购站** | 投入物品自动换钱（支持机械手自动化） | ✅ **9 格投料 + 每 10 tick 自动结算 + 漏斗/机械手接口** |
| **工厂装配核心** | 选蓝图 → 提交材料 → 一键组装 | ✅ **读 `config/deepspacedeployer/blueprints/*.nbt` → 材料校验 → 计时 → 前方落地** |
| **焊接台** | 联动 Synaxis / Sable 焊接；**高级才有开关碰撞** | ✅ **焊接工厂造的结构 → 物理结构；高级可开关碰撞（反射调用 + 兜底）** |

**经济规则**：六家公司各一种票据；收购价 = 数据包价格 × 等级倍率（低级 0.8 / 中级 1.0 / 高级 1.2）；
声望 = 累计消费 ÷ 1000，按玩家 × 公司记录；花钱**先扣方块内该账户余额、再扣卡上余额**。

**价目表**：`data/deepspacedeployer/shop/<公司>.json`，`/reload` 生效，不用重编译。

**开机规则**：手持「深空银行卡」右键方块 → 卡插进去、方块亮灯、机器可用（卡里有没有钱都行）。

**世界里的工厂**：六家公司在世界上建厂，同一个等级里随机是某一家；低级厂常见于平原/森林、
中级在沙漠/针叶林/丘陵、高级只在山地等极端群系。厂房里有商店终端、收购站（中级加工厂核心、
高级加焊接台），墙角的箱子里还有本公司票据。想立刻看一座：`/place structure deepspacedeployer:factory_skimmer_high`。

**银行卡 = 账户指针**：右键银行卡可以填写玩家名/UUID 绑定账户；
插卡后购买**优先扣该账户存在方块里的钱**；卡留在方块里没取走时，**别人也能用它花卡主的钱**（公户卡玩法）。

## 界面主题（HTML + CSS）

机器界面可以由玩家自定义：主题放在 `<版本文件夹>/deepspacedeployer/theme/`，
`custom/<名字>/index.html` + CSS 就是一套主题，缺失的资源自动回退 `default/`。
**没有 JS**，动起来靠 `{{占位符}}` / `data-if` / `data-repeat` / `data-action`。
渲染器是项目自带的（**不依赖 Chromium，玩家零安装**），并且**能离线出预览图**。

> 完整规则见 [docs/开发文档/界面主题系统.md](docs/开发文档/界面主题系统.md)。

## 自检

**进游戏后第一件事**：跑 `/dsd selftest` —— 一次性检查注册、价目表里的物品 id、蓝图读取、
配置值、声望存档、联动桥，并把结果写进日志（出问题把那段发出来即可）。

```powershell
python tools\validate.py       # 工程侧自检：贴图/模型/方块状态/语言文件/掉落表/工具标签/18 份结构/世界生成链路
python tools\check_mod_ids.py  # 物品 id 校验：拿整合包里真实的模组 jar 核对每个 id 是否存在（含 JarJar 内嵌 jar）
python tools\make_release.py   # 打发布包：release\deepspacedeployer-<版本>.zip（jar + 文档 + 素材 + 上传清单）
```

游戏内指令一览：

| 指令 | 谁能用 | 作用 |
|---|---|---|
| `/dsd guide [card\|buy\|factory\|weld]` | 所有人 | 游戏内快速上手 |
| `/dsd selftest` | 所有人 | 一键自检（注册/价目表/蓝图/配置/声望/联动/世界生成） |
| `/dsd integration` | 所有人 | 联动探测报告（Sable / Photomancy / Synaxis 的可用方法） |
| `/dsd reloadblueprints` | OP | 重读蓝图文件夹 |

> 💡 **查原版行为的小抄**：构建一次之后，`build\moddev\artifacts\neoforge-21.1.248-sources.jar`
> 里是**反编译好的 Minecraft + NeoForge 源码**（6300+ 个 .java）。想知道某个 API 到底怎么表现，
> 解压后直接读，比猜可靠得多。
