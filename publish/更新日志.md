# 更新日志

## 0.1.11 —— 修界面错位 + UI 编辑器（第 1 步：文件浏览器）（2026-10-19）

### 修：物品 / 玩家背包错位（老板实机截图）
主题用 `data-slot="input9"` 标记"物品格摆哪儿"，**但没有任何代码去读它**：

- `WebViewScreen.markers()` 写好了，全仓库没有一处调用；
- 原版槽位一直停在 `MachineMenu` 里写死的坐标（卡槽 8,20；3×3 从 8,44；背包 63,186）；
- 两边坐标体系不同 → 物品飘在框外、3×3 格子和画的框错开、玩家背包跑到界面最下面。

修法：
- 新增 `ui/webview/ThemeSlotLayout`，把原版 `Slot` 按标记摆放（单个 / 网格 / 玩家背包 3×9+快捷栏）；
- `MachineScreen` 每次主题重新布局后调用，卡槽 / 3×3 / 剪贴板 / 市场三格 / 玩家背包各自归位；
- `Slot.x/y` 原版是 `final` → 用 NeoForge **AccessTransformer** 放开
  （`META-INF/accesstransformer.cfg`），`build.gradle` 里显式声明；
- `theme.css`：`.slots9` 38→54（3×3 个 18px 格子应该是 54）、`.slotgrid` 40→56。

### 新：主题编辑器（第 1~2 步）
主题选择界面里**选中任意一个包**（不管启用/未启用）→ 底部「编辑…」亮起 → 进入编辑器。

- **三栏布局**：左 = 目录树（首项 `..` 返回上级，MT 管理器那种），中 = 预览，右 = 文件信息；
- **预览**：`.json/.css/.txt` 显示文本（可滚动）；`.png/.jpg` 渲染图片（等比缩放）；
  `.html` **直接渲染主题效果**；
- **右键菜单**：复制 / 剪切 / 粘贴 / 重命名 / 删除（重命名带输入框对话框）；
- **文本可编辑并保存**（第 2 步）：
  - 选中 `.json/.css/.txt/.md/.js` 就在中栏直接改：字符输入、回车、退格、方向键、Home/End；
  - 光标闪烁、行号:列号显示、`●` 表示有未保存改动；
  - 点「保存」或 **Ctrl+S** 写回磁盘；如果改的是当前启用主题的文件，
    **游戏内界面会自动重新加载**（`WebViewManager.markThemesDirty()`）；
- 编辑器是**模组内置界面，不受任何主题影响**（不读主题里的 html/css）。

### 新：组件层（第 3 步）
选中 .html 后，右栏出现**组件库**：+ 文本 / + 按钮 / + 物品框 / + 图片。

- 点一下加进画布，**鼠标拖动**改位置、**拖右下角把手**改大小；
- 右栏显示 x / y / 宽×高 / 图层，层+ / 层- 调图层（最小 -1）、删除 移除；
- 点「保存到 html」写回文件：组件存成
  <!-- editor:begin --> … <!-- editor:end --> 之间的 <div data-editor=… style=position:absolute;left…>，
  **不动文件里原有的内容**；
- 这些组件是**摆设**（不参与方块逻辑），符合老板定的规则；
  点空处即取消选中、选中框可拉伸。

### 新：修改资源（第 4 步）
- 选中**图片组件** → 右栏「换图片…」→ 弹**系统文件选择器**（AWT FileDialog，守护线程里弹、
  不卡游戏）→ 选好后弹**重命名对话框**（只显示不带后缀的名字）→ 保存时
  **复制到主题根目录**（自动补回原后缀）并挂到该组件上；
- 组件把图片存成 ackground-image:url('xxx.png')，存进 html。

### 新：图层真的生效了（渲染器支持 z-index）
- `Style` / `CssParser` 新增 `z-index`；`ThemeRenderer` 按它**稳定排序**后再画子元素；
- 不写 `z-index` 的元素行为和以前完全一样；**背景想垫底就写 -1**。

### 新：画布上直接改主题里**已有**的元素（第 5 步）
- 渲染器新增"节点 → 源码位置"（`HtmlNode.srcTagStart/srcTagEnd`，解析时记下开始标签的范围）；
- 编辑器里点中栏的任意已有元素 → 黄框选中、显示 `标签 宽×高`；
- **拖动它** → 实时移动；点「保存到 html」把新位置合并进该元素的 `style`（`left/top`），
  其余内容一个字不动。多个元素从后往前改，偏移不会互相影响；
- `data-repeat` 克隆出来的节点没有源码位置（`srcTagStart = -1`），自动跳过。


> 后续步骤（已列入待办）：组件库拖入画布、选中出属性面板、拉伸改大小、图层、
> 修改资源（系统文件选择器），以及"逻辑编排器"（参考 Scratch）。

## 0.1.6 —— 修好"主题界面一片空白"，主题选择改成资源包式（2026-10-18）

### 修：点开主题界面只看到一层灰色，什么都没有
根因比看上去严重：**主题从来没真正画到屏幕上**。

- 算布局时用的是"只量不画"的画布（为了量文字宽度），但真正绘制时**没有换成绑定屏幕的画布**；
- 结果：元素位置全都算对了、日志一切正常，可一个像素都落不到屏幕上；
- 受影响的不只是主题选择界面 —— **所有**主题化界面都是这样；
- 离线预览 `gradlew renderThemes` 用的是另一套画布，所以这个 bug 一直没被抓到。

现在每帧渲染前都会把"这一帧的画布"交给渲染器，并加了断言盯住这件事。

### 修：创造模式背包里看不到主题按钮
生存和创造模式的背包是**两个不同的类**（`InventoryScreen` / `CreativeModeInventoryScreen`），
之前只处理了生存。现在两个都会挂上按钮，键位「按钮移动」在两种模式下都能用。

### 新：资源包式的主题选择界面
打开方式不变（按 **E** → 点那颗圆形「主题」按钮）。

- **左右两栏**：左边 = 可用（未启用），右边 = 已启用；
- **点左边的主题 → 移到右边（启用）**，点右边的 → 移回去（禁用），**可以同时启用多个**；
- 每套主题显示：**图标 / 名称 / 版本 / 作者 / 介绍**；
- 底部有 **「高级界面设置…」**：
  - 给**每个界面**单独指定用哪套主题（10 个界面两列列出，点一下循环切换）；
  - 点「**应用**」后自动启用被指定到的主题；
  - 启用**别的**主题时会**清空**这套自定义配置（界面上有黄字提示），
    之后所有界面都归新主题渲染；
  - **禁用**某个主题时，它负责的界面**回落到默认主题**（例如禁用主题 2，原来用它的方块 A 变回默认）。
- 界面配色照默认主题的深色工业风。

### 新：主题图标
- `index.json` 新增一个字段 **`"icon": "icon.png"`** —— 相对**主题文件夹**、和 `index.json` 同级；
- **默认主题自带 `icon.png`**（就是模组图标）；
- 自定义主题**不写图标也会显示默认图标**（自动回退到 `theme/default/` 的同名文件）。

### 修：启动器（PCL2 等）的模组列表不显示图标
jar 根目录多放了一份 `logo.png`（很多启动器会找这个名字），
`neoforge.mods.toml` 里的 `logoFile` 保持不变 —— 游戏内模组列表仍然正常。

### 说明：主题选择界面为什么不做成"可主题化"
这个界面需要滚动列表、多选、循环切换，自研的 HTML 子集做不可靠，
所以用原生控件实现。默认主题里的 `choice.html` 仍然保留（离线预览 / 主题作者参考用），
但游戏内不再加载它 —— 十个可主题化界面里，这一项改成了原生。

## 0.1.4 —— 让玩家看到自己文件夹里的载具（2026-10-17）

### 修：载具打印机只认 `Sable-Schematics`，玩家放在 `schematics` 里的图纸看不到

老板反馈："载具打印机不能打印**客户端**的载具，只能读取到**服务端**的载具 /
我想让玩家可以看到自己存在文件夹里的载具"。

排查后发现是**两个文件夹的事**（实测老板的实例里就有）：

| 文件夹 | 实测数量 | 之前读不读 |
|---|---|---|
| `versions\孢子危机\Sable-Schematics\` | 7 个 `.nbt` | ✅ 读（走 Sable 官方接口）|
| `versions\孢子危机\schematics\` | **10 个 `.nbt`** | ❌ **不读** —— 就是"看不见"的那批 |

`schematics` 是**机械动力（Create）的图纸夹**，玩家习惯把载具存那儿。

**修法**：把"要扫的玩家文件夹"做成数组 `USER_DIRS`
（现在是 `enxv_aeronautics_structures` + **`schematics`**），
每个文件夹都走同一段扫描逻辑（读 `.nbt/.excraft/.schem` → `SableBlueprint.load(CompoundTag)`）；
**读不了的文件只打 WARN 跳过**，不会因为一张坏图纸就让整个列表消失。

- 界面的"蓝图文件夹提示"也跟着更新为：`Sable-Schematics / enxv_aeronautics_structures / schematics`；
- 台账日志改成：`物理蓝图已加载：N 份（来源：Sable-Schematics + enxv_aeronautics_structures + schematics）`；
- 加新文件夹只需往 `USER_DIRS` 里塞一个名字，不用再写扫描代码。

> ⚠️ 多人的边界说明：服务端只能读**自己这台机器**上的文件夹。
> 联机时玩家本机 `schematics` 里的图纸服务端看不到 —— 要做到那一步得让客户端把文件传给服务端
> （上传 + 服务端落盘），比现在这一版复杂得多，先不做。

### 怎么用

1. 把载具图纸（`.nbt`）放进 **游戏目录**下的 `schematics\`（或 `Sable-Schematics\`）；
2. 打开载具打印机界面 → 点一次 **「刷新蓝图」**（不用重启游戏）→ 列表里就会出现；
3. 如果某张图纸读不了，日志里会有一条 `[深空铸造体] schematics 里的 xxx 读不了（也许不是 Sable 蓝图）`。

## 0.1.3 —— 收购投送机「为什么不工作」诊断（2026-10-17）

### 修：新存档里收购投送机"无论如何都不工作"，而且一点提示都没有

收购循环有 **5 道关卡**，每一道失败原先都是**静默 `return false`** —— 界面和日志都不吭声，
玩家只能干瞪眼（这就是老板说的"无论如何都不工作"）：

1. 槽里**没有银行卡**；
2. **银行卡还没绑定账户**（新存档/新卡最常见的一种）；
3. **自动收购开关关着**；
4. **头顶有整块方块挡住**（老板之前定的规则：一路扫到世界顶）；
5. 投入的东西**不在这家公司的收购清单里**。

现在：

- 新增原因码 `MachineMenu.DATA_IDLE_REASON`（0 = 正常，1~5 = 上面五种）；
- **界面直接显示**，例如「未工作：银行卡还没绑定账户（右键卡绑定）」——
  原生界面画在原来的空档（y=78），主题界面用 `buyer.html` 里的 `data-if="未工作"`，两套都能看到；
- **日志也写一条**：`[深空铸造体][收购诊断] 位置=… 状态=…`
  （**只在原因变化时**写，不会刷屏）。

> 排查"它不动"的正确顺序：先看界面那行字；界面没看到就搜日志里的 `[收购诊断]`。

## 0.1.2 —— 主题入口挪到背包界面 + 图标换真图（+ 发布包不再入库）

### 主题入口：ESC 菜单 → 背包界面里的圆形按钮
- **修**：在 ESC 菜单点「界面主题」**不响应 / 延迟响应 / 点了要先"继续游戏"才弹出** ——
  暂停菜单自己的生命周期太脆（打开即暂停、点击后状态回收），在它上面开新界面时机不可靠；
- 按老板要求参考 FTB 的做法，入口挪到按 **E** 打开的背包界面：
  - **左键点击** → 打开主题选择界面；
  - **右键长按拖拽** → 拖到任意位置，**松手即记住**（写进 `ui.theme_button_x/y`）；
  - 换分辨率 / 改界面缩放后自动拉回可视范围，不会"消失"；
- ESC 菜单上的主题按钮删掉（那里只留 OP 的「价目表编辑器」）。

### 图标
- **按钮图标**：老板给的像素图 → 抠掉"画进图里的浅蓝棋盘格"背景（原图没有 alpha 通道）
  → 48×48 透明贴图（`assets/deepspacedeployer/textures/gui/theme_button.png`）；
- **按钮加深蓝描边**（`#14215E`），浅色界面上也看得清；
- **模组图标（128×128）** 一并换成这张图的透明版（`deepspacedeployer_logo.png`）；
- 处理工具入库：`python tools/process_theme_icon.py <原图> --out <目录>`
  （只用 Python 标准库；`--report` 只看测量不写文件）；原图与产物归档在 `art/模组图标/`。

### 发布方式变更（重要）
- **发布包 `release/*.zip` 不再入库**，改挂 **GitHub Releases**。
  原因：zip 是每次打包都会变的二进制，入过库以后，下一版删旧包时会和
  "还留着旧包的分支"产生【删 / 改】冲突，Git 没法自动合（PR 上真卡住过）。
  本地照常用 `python tools\make_release.py` 打包，上传到 Releases 页即可。

## 0.1.1 —— 界面主题：用 HTML + CSS 自己画界面

### 界面主题（新）
- **所有方块界面都能由玩家用 HTML + CSS 自己写**：商店、收购投送机、载具打印机、寄售市场、
  资金转化、投放点选择、银行卡绑定、通用终端、价目表编辑器
- **主题放在游戏目录**：`<版本文件夹>/deepspacedeployer/theme/`
  - `default/` = 模组内置的默认主题（首次进游戏自动释放）
  - `custom/<你的主题名>/` = 你自己的主题，**模组永不改动**
  - 一个界面一个文件（`buyer.html` / `market.html` / …）；**缺文件自动用默认主题的那一份**
- **资源引用**：`/default/a.png`（用默认主题的图）、`./a.png`（用你自己的图）；
  自己目录找不到就自动去 `default/` 找
- **不需要 JS**：动起来靠 `{{占位符}}`、`data-if`、`data-repeat`、`data-action`
- **换主题**：ESC 菜单 →「界面主题」（所有玩家可用），点一下立刻生效
- **主题写坏了不会有事故**：界面安静地退回原来的样子，绝不会打不开；
  也可以在配置里 `ui.theme_enabled = false` 整体关掉

### 给做主题的人的工具（不用开游戏）
- `gradlew checkThemes` —— 十个界面逐个加载 + 布局，报出溢出与用到的动作
- `gradlew renderThemes` —— 每个界面渲染成 PNG（`build/theme-preview/`），肉眼过一遍
- `gradlew dumpTheme -Pfile=buyer.html` —— 排版分解，查"谁把内容撑高了"

### 其它
- 机器界面窗口从 288×270 加高到 **288×300**（给主题留出排版空间，物品格位置不变）
- 修掉两个布局引擎问题：写了固定高度的容器会被内容撑高（导致溢出）、根容器不受视口约束
- `docs/开发文档/` 新增两份文档：**自定义主题开发文档**、**界面清单**

> **为什么不用真正的浏览器内核**（Chromium / JavaFX）：
> Chromium 的原生库要玩家联网下载（还要先装别的模组），JavaFX 三个平台加起来约 148 MB
> 且缺库会直接崩 JVM —— 都不符合"内置、玩家零安装"的要求。
> 详细对比见 `docs/开发文档/自定义主题开发文档.md` 第零节。

## 0.1.0 —— 首发（Minecraft 1.21.1 / NeoForge 21.1.x）

第一个公开版本。功能覆盖：世界生成、经济、商店、蓝图工厂、焊接、物理结构与管理员工具。

### 六家公司与经济
- 六家公司：阈限实验集团、低语环带科技、断锷军械财团、掠影推进公司、磐基重工工业、星联动力联盟
- 六种货币（票据）互不通用；跨公司兑换收 20% 手续费（可配）
- **银行卡**：绑定玩家账户、给卡改名；钱按玩家分账存在方块里，消费先扣方块内余额再扣卡上余额
- 卡留在机器里不取走时，其他玩家也能用它花卡主的钱（公户卡玩法）
- **声望**：按"玩家 × 公司"累计消费记录，高级商品需要声望解锁

### 四种功能方块（4 机器 × 6 公司 × 3 等级 = 72 种外观）
- **工厂终端（商店）**：插卡开机、存票据、取现、跨公司兑换、按页购买（等级 + 声望双重解锁）
- **工厂装配核心**：选蓝图 → 投材料（显示有/需）→ 一键组装 → 计时 → 落地
  - 支持**俯视图选投放点**（真实地形采样成地图，范围 96 格）
  - 材料 + 每方块组装费 + 组装时间三重要求；低级/中级/高级上限 200/800/4000 方块
  - 装了 Sable 时自动把成品组装成物理结构
- **焊接台**：把工厂刚造的结构焊成物理结构；**高级**才有开关碰撞与解散结构
- **收购站**：投料自动换钱（支持漏斗与机械手），收购价按等级 0.8× / 1.0× / 1.2×

### 蓝图与自建工厂
- 蓝图来源：`config/deepspacedeployer/blueprints/*.nbt`（机械动力/原版结构格式），`/dsd reloadblueprints` 重读
- **蓝图凭证**：商店购买某份结构的使用权，对工厂核心右键即选中
- **公司授权铭牌**：把自建机器改造成指定公司（机器里有钱时禁止改，防套利）
- **等级升级套件**：把机器升一级（低→中→高）
