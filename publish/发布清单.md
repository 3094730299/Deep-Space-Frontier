**发布前建议改一下 `gradle.properties`**：

```properties

mod_license=All Rights Reserved   # 想开源就换成 MIT / LGPL-3.0 等
```

## 1. CurseForge

1. 注册/登录 → **Author Dashboard** → **Create Project** → 选 **Minecraft** → **Mods**
2. 名称：`Deep Space Deployer`（中文名可以写在描述里）
3. **Summary（摘要，一句话）**：
   > Six interstellar companies build factories across your world. Trade, print blueprints, assemble and weld physics structures.
4. **Description**：粘贴 `publish\描述-中文.md` 的内容
5. **Categories**：`Technology`、`World Gen`、`Economy`（如有）、`Adventure`
6. **Game Version**：`1.21.1`；**Modloader**：`NeoForge`
7. **License**：和你 `gradle.properties` 里写的一致
8. **Relations（依赖）**：
   - Required：`Create`（机械动力）
   - Optional：`Create: Aeronautics`、`Sable`、`Sable Photomancy`、`Synaxis`
9. **Upload File**：把 jar 拖进去，Release type 选 `Release`（当前 0.1.17）
10. **Gallery**：上传两张展示图 + 封面

## 2. Modrinth

1. **Create a project** → **Mod** → 名称 `Deep Space Deployer`
2. **Description**：粘贴 `publish\description-en.md`
3. **Environment**：Client **required**、Server **required**（我们是服务端权威，多人必须两边都装）
4. **Loaders**：`NeoForge`；**Game versions**：`1.21.1`
5. **Dependencies**：同上（Create 必选，其余可选）
6. **Gallery**：封面 + 两张展示图
7. **Version**：上传 jar，填版本号 `0.1.17+mc1.21.1`、渠道 `Release`、更新日志

### 先看这条：发布包放在哪（2026-10-17 定）

**release/*.zip 不入库**，改用 **GitHub Releases** 挂出去：

- 本地照常打：python tools\make_release.py → release\deepspacedeployer-<版本>.zip
  （里面是 jar + 文档 + 素材 + 上传清单）；
- 发版时在仓库 **Releases → Draft a new release** → 填 tag（如 v0.1.2）、
  上传那个 zip 和 build\libs 里的 jar；
- ⚠️ **不要 git add -f release/xxx.zip**：zip 是每次打包都会变的二进制，
  一旦入库，下一版删旧包时就会和还留着旧包的分支产生【删 / 改】冲突，
  Git 没法自动合（PR 上真卡住过一次）。verify_readme_claims.py 里有一条断言专门盯着这件事。

## 3. 发布前自查（每次都要过一遍）

```powershell
.\gradlew.bat build          # 必须 BUILD SUCCESSFUL
python tools\validate.py       # 必须 [OK] 全部检查通过
python tools\check_mod_ids.py  # 必须 [OK]（核对商品表/蓝图里的物品 id 在整合包里真的存在）
```

进游戏再确认三件事：

- [ ] `/dsd selftest` 全绿（注册、价目表、蓝图、配置、世界生成都在）
- [ ] 创造模式能拿到所有物品：银行卡、六种票据、蓝图凭证、升级套件、六张授权铭牌、四种机器方块
- [ ] `/place structure deepspacedeployer:factory_skimmer_high` 能放出一座高级厂

**版本号规则**（在 `gradle.properties` 的 `mod_version` 改）：
`0.1.0` 首发 → `0.1.1` 修 bug → `0.2.0` 加功能 → `1.0.0` 稳定版。
