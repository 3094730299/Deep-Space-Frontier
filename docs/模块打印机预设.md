# 模块打印机预设格式

> 模块打印机只读 **服务端预设**，不读玩家自己的 Sable 蓝图。  
> 载具打印机仍读玩家 Sable + `config/deepspacedeployer/vehicles/` 预制载具。

## 目录

```text
config/deepspacedeployer/
  vehicles/              ← 载具打印机的服务端预制载具（可选）
    xxx.nbt
  modules/               ← 模块打印机专用
    xxx.nbt              ← 必填，Sable 蓝图本体
    xxx.json             ← 可选，价格/等级/公司/显示名
```

- `.nbt` 必须是 Sable 蓝图（和 `Sable-Schematics` 里能读的格式一致）；
- 文件名（去掉 `.nbt`）就是内部 key；
- 同名 `.json` 负责 UI 显示和收费；
- 没有 `.json` 时默认：显示名=文件名、价格=5000、最低等级=低级、公司=不限。

## JSON 字段

```json
{
  "display": "居住舱模块",
  "price": 5000,
  "tier": "mid",
  "company": "threshold"
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `display` | string | 界面显示名 |
| `price` | 整数 | 打印价格，只扣**这台模块打印机所属公司**的账户余额 |
| `tier` | `low` / `mid` / `high` | 最低机器等级；低于该等级不显示/不能打印 |
| `company` | string | 限定公司 id；留空或省略 = 所有公司都能打印 |

公司 id：

```text
threshold / whisperbelt / brokenedge / skimmer / bedrock / astralink
```

## 行为

- 模块打印机是**新机器**，6 家公司都有，每台按方块等级有低/中/高；
- 列表只显示 `modules/` 里的预设，并按 `tier` / `company` 过滤；
- 打印**不消耗材料**，只扣本公司账户余额；
- 价格在 JSON 里预设；生成失败会退款；
- 和载具打印机一样：点「选投放点」在周围地图选位置，确认后直接生成**物理结构**；
- 目标默认在玩家面向方向前方 3 格；头顶/周围空间不够会拒绝；
- 模块预设不会出现在载具打印机里；玩家自己的 Sable 也不会出现在模块打印机里。

## 重载

改完 `modules/` 后，OP 执行：

```text
/dsd reloadblueprints
```

会同时重读载具蓝图、`vehicles/` 预制载具和 `modules/` 模块预设。

## 当前状态

系统已实现；仓库里**没有附带模块预设**，所以第一次打开列表是空的。  
把整合包/自己做的模块 `.nbt` + `.json` 丢进 `config/deepspacedeployer/modules/` 即可。
