# 深空铸造体 · 玩法手册（给玩家看的）

> 一句话：**世界上有六家星际公司的工厂，去他们的厂里卖材料赚钱、买模块、用蓝图造载具。**

---

## 一、四样核心东西

> 💡 **不想翻文件？** 游戏里敲 `/dsd guide` 就能看到快速上手；
> 细看用 `/dsd guide card`（银行卡）、`buy`（赚钱）、`factory`（造结构）、`weld`（焊接）。

| 名字 | 长什么样 | 干什么 |
|---|---|---|
| **深空银行卡** | 一张棕金色卡（带金色芯片与"T"标记） | 插进机器才能开机；卡上写着"这个账户是谁的" |
| **票据**（六种） | 六家公司各一种纸币 | 就是钱。**各公司之间不通用**，兑换要手续费 |
| **工厂终端**（商店） | 带屏幕的机器 | 存钱/取现/兑换、按公司价目表买模块 |
| **收购站** | 带漏斗的机器 | 往里丢东西自动换钱（漏斗/机械手也能塞） |
| **工厂装配核心** | 带齿轮的机器 | 选蓝图 → 投材料 → 一键组装出结构 |
| **焊接台** | 带焊枪的机器 | 把造好的结构焊成"物理结构"（高级才有开关碰撞） |

---

## 二、开局 5 分钟

1. **找厂**：`/locate structure deepspacedeployer:factory_threshold_low` 找最近的工厂；
   或者自己飞出去找（平原/森林最容易遇到低级厂，山地才有高级厂）。
   等不急就 `/place structure deepspacedeployer:factory_skimmer_high` 直接放一座。
2. **拿卡**：创造模式物品栏里拿「深空银行卡」。
3. **绑卡**：手持卡 **右键** → 填自己的游戏名 → 绑定。绑完之后这张卡=你的账户。
4. **开机**：手持卡右键工厂里的**终端**，卡插进去、机器亮灯、界面自动打开。
   - **不插卡也能打开界面**（老板要求）：空手右键机器就能看价目表、选蓝图、翻收购清单；
     要**买/组装/结算**的时候才需要把卡放进界面左边的卡槽（或者手持卡再右键一次机器）。
5. **赚钱**：到**收购站**插卡，把铁锭、安山合金、精密构件这些丢进 3×3 格子，自动按收购价换成票据。
   右边的收购清单**一屏 3 行，其余滚轮看**（右侧有滑条）。
6. **花钱**：回**终端**，在商品列表里**滚轮上下翻**，点「买」。

## 三、钱的三条规则（很容易记错）

- **公司账户是"你在这家公司的存款"，全图通用**：你在 A 厂卖货赚的钱，去这家公司**任何一座**工厂/商店
  都能直接花（以前是按方块各存各的，现在改掉了）。账户存在世界存档里，**拆机器、搬家都不会丢**。
- **花钱顺序**：先扣「你在该公司的账户余额」→ 不够再扣「卡上余额」。
- **两个方向的搬运都在终端里做**（下面有输入框）：
  | 按钮 | 意思 |
  |---|---|
  | **存票据** | 把背包里这家公司的票据存进公司账户 |
  | **存入卡内** | 公司账户 → 银行卡（把钱提到卡上，带着卡走到哪都能花） |
  | **取现** | 公司账户 → 票据物品（拿在手里跟人交易） |
  | **卡转余额** | 银行卡 → 公司账户 |
  | **兑换** | 把卡上其它五家公司的余额换成本公司（扣手续费） |
  | **余额** | 在聊天栏报一次账 |

  「存入卡内 / 取现 / 卡转余额」都要先在输入框里填**金额**（只认数字），再点按钮。

**公户卡玩法**：卡插在机器里没取走时，**别人也能用这台机器花你的钱**。
所以把卡留给朋友 = 给他一张公司信用卡；不想被刷就把卡拔走。

> ⚠️ **拆机器会发生什么**：挖掉机器时，方块本身、里面的银行卡、投料格里的东西、
> 材料缓冲、以及**方块里所有人的余额**都会掉出来（余额换成本公司票据）。
> 所以搬家时放心挖 —— 但记得把地上的东西捡干净（票据谁捡到算谁的）。

## 四、跨公司：兑换

公司之间票据不通用：

1. 在 A 公司把票据**取现**（或直接存进卡上余额）
2. 去 B 公司的终端，点「**兑换成本公司**」
3. 默认扣 **20% 手续费**（服务器可配），换完钱进 B 公司票据

所以"低买高卖跑商"是可行的：每家公司的**收购价和商品价格都不一样**，而且**低级厂收购价压到 0.8 倍、高级厂给 1.2 倍**。

## 五、工厂：用蓝图造东西

### 5.1 直接造（自己有蓝图）

1. 右键**工厂装配核心**打开界面（不插卡也能开）→「蓝图」页**滚轮上下翻**选一份蓝图
   （工程自带 `test_platform` 31 方块 / `small_airship` 84 方块），点「选」
2. 切到「材料/组装」页 → 把材料丢进 3×3 投料格（数字会从红变绿）
3. **把银行卡放进左边的卡槽**（组装费要从卡上那个账户扣）→ 材料齐了点「**一键组装**」
   - 校验顺序：材料 → **机器前方 3 格场地** → 组装费（每方块 20 票据）
   - 场地不够会提前拒绝，**不会白扣钱**
4. 计时结束（低级 20 秒 / 中级 12 秒 / 高级 6 秒）→ 结构**真正落地**（箱子里的东西也一起放进去）
5. 装了 Sable 的话，落地后会自动把这份结构**组装成物理结构**（能浮空、能装引擎、参与物理计算的那种）
   - 聊天栏会提示"已组装为物理结构 <编号>"；没成功会说明原因（比如没装 Sable）

**等级限制**：低级厂最多造 200 方块、中级 800、高级 4000。

### 5.1.1 自己选落点（俯视图选点）

不想让结构落在机器正面？在材料页点「**选投放点**」：

- 会打开一张**俯视图**（用真实地形采样出来的：颜色是方块的地图色，明暗是高度）
- **蓝框** = 工厂核心的位置，点地图任意位置 → **金框** = 你要的落点
- 「回到机器位置」可以一键选回机器脚下；「确认投放点」发到服务器
- 落点最远 **48 格**（服务器可配 `factory.assembly_max_radius`），太远会拒绝
- 结构会**以落点为中心**展开，高度贴合地形；材料页会显示"投放点：已在地图上选定"
- 不选也行 —— 默认还是落在机器正面 3 格

### 5.2 在商店买"物理结构使用権"（蓝图凭证）

商店里除了模块，还会卖**蓝图凭证**（六家公司各有自己的报价）：

1. 在**终端**商品列表里找到「蓝图凭证」（条目上会写是哪份结构、多少钱）
2. 买下来 → 得到一张图纸样子的凭证，**上面写着蓝图名**
3. 拿着它对着**工厂装配核心右键** → 核心立刻选中这份蓝图（凭证消耗掉）
4. 接着按 5.1 投材料、一键组装

> 凭证只能"选中蓝图"，材料还是得自己备 —— 相当于花钱买**图纸的使用权**。
> 如果服务器上没有这份蓝图文件，用的时候会明确提示，不会白花（管理员把 `.nbt` 放进
> `config/deepspacedeployer/blueprints/` 后 `/dsd reloadblueprints` 即可）。

## 六、资金转化界面（所有和钱有关的操作都在这里）

在**工厂终端（商店）**界面里点左下角的「**资金转化**」按钮，就打开这个界面：

```
┌─ 资金转化 ───────────────────────────────┐
│ ← 返回商店                                 │
│  卡1（转出）        →        卡2（转入）     │
│  ┌──┐                        ┌──┐        │
│  └──┘                        └──┘        │
│  卡主：xxx                    卡主：xxx     │
│  卡上：1200                   卡上：0       │
│  [ 金额输入框 ]  [+100][+1000][+1万]       │
│  [ 卡1 → 卡2 ]  [卡转余额] [存入卡内]        │
│  [ 存票据 ]     [ 取现 ]                   │
│  [ 兑换 ]       [ 余额 ]                   │
└────────────────────────────────────────┘
```

| 按钮 | 意思 |
|---|---|
| **卡1 → 卡2** | 从一张银行卡**直接转到另一张**（同一家公司之间转，**不收手续费**） |
| **存票据** | 把背包里这家公司的票据存进公司账户 |
| **存入卡内** | 公司账户 → 银行卡（把钱提到卡上，带着卡走到哪都能花） |
| **取现** | 公司账户 → 票据物品（拿在手里跟人交易） |
| **卡转余额** | 银行卡 → 公司账户 |
| **兑换** | 把卡2 上其它五家公司的余额换成本公司（扣手续费） |
| **余额** | 在聊天栏报一次账 |

- 「卡1 → 卡2 / 存入卡内 / 取现 / 卡转余额」都要先在**输入框里填金额**（只认数字），
  右边三个 `+100 / +1000 / +1万` 是快捷加钱按钮。
- **卡怎么放**：**左键拖着挪就行**（和原版箱子一模一样）——
  从背包把银行卡**左键拖到卡槽上**，拿起来就放在鼠标上、再左键点卡槽放进去。
  嫌麻烦也可以**右键点卡槽**：会把背包里第一张银行卡直接拎到鼠标上，你再左键点卡槽放下。
- **关界面（ESC）时**：两个卡槽里的卡 + 鼠标上拎着的卡，**全部自动回到背包**，不会丢。

## 六·五、自己盖一座工厂

世界上的工厂是六家公司的；如果你想要一座**属于自己的**（比如把家旁边的机器改成"掠影推进公司·高级厂"）：

1. 去那家公司的商店买「**授权铭牌**」（2500 票据，需要该公司中级厂 + 声望 10）
2. 对自己放的机器**右键** → 这台机器就变成那家公司的了（货币、外观、商品池、收购表全跟着换）
3. 想升级：买「**等级升级套件**」（磐基重工/星联动力在卖）→ 右键机器升一级，低→中→高（要连用两个）

> ⚠️ 机器里还存着钱的时候不能改公司 —— 先把余额取空（终端点「取现」）。

**银行卡还能改名**：手持银行卡右键 → 在「卡名」里填个字（例如"公司公户卡"）→ 点「重命名」。
名字会显示在背包和工具提示里，多人服务器上有多张卡时特别有用。

## 七、管理员/服主工具

| 指令 | 作用 |
|---|---|
| `/dsd reloadblueprints` | 改完蓝图文件夹（`config/deepspacedeployer/blueprints/`）后重新读取 |
| `/dsd integration` | 打印联动探测报告（哪些模组装了、能调到哪些方法）—— 出问题就把这份发出来 |
| **ESC 菜单左侧「价目表编辑器」** | 只有 OP 能看到：可视化改商品/价格/等级门槛/收购清单，点「保存」写进世界数据包 |

改价格还有一条路：直接编辑 `data/deepspacedeployer/shop/<公司>.json`（世界数据包里也有一份），然后 `/reload`。

## 八、多人服务器注意事项
- 所有逻辑都在**服务端**判定（价格、余额、权限、组装），客户端改不了数据
- 一座工厂可以多人共用：谁操作就按"卡上那个账户"扣钱（配合上面的"公户卡"玩法）
- 收购站支持**漏斗和机械手**自动投料，可以做全自动卖铁流水线
- 帐号余额、声望存在存档里；声望 = 累计消费 ÷ 1000，高级商品需要声望才解锁
