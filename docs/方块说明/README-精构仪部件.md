# 精构仪部件（precision_fabricator_part）

> 方块 ID：`precision_fabricator_part`  
> 归属：精构仪（`precision_fabricator`）的部件  
> 作用：组成 1×1×5 装饰性多方块

## 一句话

精构仪的 4 个部件格，**不是独立机器**。放主体时自动生成，不要手动放。

## 生成

- 放置 `precision_fabricator` 主体时自动生成；
- 主体左右各 2 格，共 4 个部件；
- 部件没有方块实体，不画自己，但占碰撞。

## 使用

- 没有菜单；
- 没有功能；
- 不能单独操作；
- 拆任意一个部件会把精构仪主体一起拆掉。

## 注意

- 正常不要手动放；
- 它不是载具打印机部件；
- 精构仪本身只是装饰机器，不生产物品。
