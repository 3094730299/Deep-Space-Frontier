# 深空货币银行

> 方块 ID：`currency_bank`  
> 归属：全局方块  
> 等级：无  
> 作用：36 种实体币存取、转账、挂失、免费取卡

## 一句话

拿着自己的银行卡右键银行，打开功能主页；所有和“钱在卡里/实体币/账户”有关的操作都从这里进。

## 放置/打开

- 单格方块，全球通用，不属于任何公司；
- **手持银行卡右键**打开；
- 没有卡时不能办理业务；
- 银行方块本身没有库存/等级/公司。

## 功能主页

主页有四个子界面：

1. **取钱/存钱（实体货币）**
2. **转账**
3. **挂失**
4. **免费取卡**

每个子界面左上角有「返回」。

## 取钱/存钱

- 支持 6 家公司 × 6 种面额 = **36 种实体货币**；
- 卡槽放本人卡；
- 选公司/面额/张数；
- 可以存入选中、全部存入、取出；
- 存取不收税；
- 实体币占背包格，注意空间。

## 转账

- 两个真实卡槽（源卡/目标卡）；
- 卡槽下方列出该卡的 7 个账户（6 公司 + 通用）和总资产；
- 选择账户、填金额、确认；
- 银行内转账收 **5% 手续费**（以界面显示为准）；
- 也可以按玩家名字转账（目标需有账户）；
- 转账成功后对方账户增加净额。

## 挂失

- **只有一个卡槽，这个卡槽是“接收余额的卡”**；
- 右边从本人**其他卡**里选择要挂失的卡；
- 挂失后，丢失卡的余额转到接收卡；
- 丢失卡作废，不占“未挂失卡”的名额；
- 如果接收卡槽为空，或没有其他可挂失的卡，只提示，不会执行挂失；
- 废卡不能继续用。

## 免费取卡

- 空卡；
- 有冷却时间（默认约 5 分钟，以界面为准）；
- 取到的卡是否算 2 张上限，以当前界面提示为准；
- 创造模式可直接拿卡。

## 银行卡本身

- 手持银行卡右键（不是银行方块）可以绑定/改名；
- 卡是账户指针，不是钱包；余额在账户里；
- 卡槽插进机器才能让机器用这个账户；
- 卡被挂失后不能再用。

## 注意

- 银行方块没有方块实体；拆了不会丢账户数据；
- 账户数据在世界存档 `CompanyFunds` 里；
- 不同公司账户之间兑换有手续费（默认 20%，`economy.exchange_fee_percent`）；
- 跨公司兑换、通用账户转换等具体按钮以银行界面为准。
