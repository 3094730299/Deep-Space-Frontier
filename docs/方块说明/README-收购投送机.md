# 收购投送机

> 方块 ID：`buyer`  
> 归属：**无公司**  
> 等级：低 / 中 / 高（3 个变体）  
> 作用：投物品，按选定的公司收购价换钱

## 一句话

把要卖的东西丢进 3×3 输入格，机器按界面里选的那家公司结算。  
**等级只影响速度，不影响价格。**

## 放置

- 3 个等级变体，没有公司归属；
- 放下后可以在界面里选“按哪家公司结算”；
- 选择存在方块实体里，拆了会丢；
- 不需要多方块。

## 打开/插卡

- 空手右键打开界面；
- 插卡后才能结算（钱进卡账户）；
- 界面里可以切换结算公司；
- 收购机拒绝公司授权卡（它不需要公司归属）。

## 投料

- 3×3 = 9 个输入格；
- 可以直接丢物品，也可以接漏斗/机械手自动投料；
- 机器自动收购，不需要逐个点；
- 收购不消耗材料，只把物品换成钱。

## 价格

- 价格来自**当前选择公司**的收购价目表；
- 低/中/高三个等级**价格完全一样**；
- 不再有旧版的 0.8 / 1.0 / 1.2 倍率。

## 速度

等级决定节奏：

| 等级 | 速度 |
|---|---|
| 低级 | **1 组 / 1.5 秒** |
| 中级 | **2 组 / 1 秒** |
| 高级 | **3 组 / 0.5 秒** |

- **一组 = 一个输入格里的那叠物品**（最多 64 个）；
- 自动收购每 tick 最多处理一组；
- 手动「立即收购」按已攒的组额度处理；
- 单机上限 **64 物品/tick**、全服上限 **2000 物品/tick**；
- 处理不完的留在输入格排队，不丢。

## 自动/手动

- 界面有「自动收购」开关；
- 关掉自动后，可以点「立即收购」按节奏手动卖；
- 手动和自动共用同一份等级节奏 + 单机/全服预算。

## 阻挡

- 机器**正上方被方块挡住**时不会工作；
- 界面会提示“上方被阻挡无法工作”；
- 清理头顶方块后自动恢复。

## 钱的去向

- 收购款进插卡账户；
- 按界面选定的公司记账；
- 具体支付/找零按当前钱包规则处理；
- 收购机不产生实体币，直接进账户。

## 拆机器

- 拆掉会掉落方块、卡槽里的卡和输入格里的物品；
- 已结算的钱不会退回。
