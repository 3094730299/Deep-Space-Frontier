# 打印机部件（printer_part）

> 方块 ID：`printer_part`  
> 归属：载具打印机（`factory_core`）的部件  
> 作用：组成 3×2×2 多方块结构

## 一句话

这是载具打印机的 11 个部件格，**不是独立机器**。放核心时自动生成，不要手动放。

## 生成

- 放置 `factory_core` 时，核心会按朝向自动放置 11 个 `printer_part`；
- 核心 + 11 个部件 = 3×2×2 = 12 格；
- 部件状态里记录列/层/朝向，没有方块实体。

## 使用

- 没有菜单；
- 没有卡槽；
- 不能单独操作；
- 拆任意一个部件会触发整台载具打印机拆除。

## 注意

- 正常生存/创造都不要手动放它；
- 如果部件丢了，载具打印机会不完整；
- 它不是模块打印机部件，模块打印机是单格方块。
