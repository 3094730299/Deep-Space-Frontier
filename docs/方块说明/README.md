## 通用规则

- **银行卡**：绝大多数“花钱/收钱”的机器都要在卡槽里插卡；不插卡通常还能打开界面看，但不能成交。
- **公司**：6 家公司是阈限、低语环带、断锷、掠影、磐基、星联。带公司的机器放下后归属固定，不能在使用中换公司。
- **等级**：低/中/高影响可买商品、库存补货速度、结构大小/组装时间、模块门槛等；收购机等级只影响速度，不影响价格。
- **投放点**：载具打印机和模块打印机都可以点“选投放点”，在周围俯视图里选位置；默认落点是玩家面向方向前方 3 格。
- **物理结构**：载具打印机/模块打印机的成品是 Sable 物理结构，不是先摆方块再物理化。
- **拆机器**：机器里的卡、投料、库存等按各自规则处理；多方块机器拆任意部件会拆整台。
