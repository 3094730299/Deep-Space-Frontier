# 通用终端

> 方块 ID：`universal_terminal`  
> 归属：**无归属**  
> 等级：**无等级**  
> 作用：6 个卡槽，插哪家公司的卡就买哪家的商品

## 一句话

一个方块顶六家公司：把不同公司的银行卡插进左边 6 个卡槽，界面按当前有效卡的公司显示商品。

## 放置

- 单格装饰/功能方块；
- 无公司、无等级；
- 不需要多方块。

## 使用

1. 右键打开界面；
2. 左边 6 个卡槽放银行卡（可以放不同公司的）；
3. 界面取**第一张有效卡**的公司作为当前公司；
4. 右边显示该公司的商品列表；
5. 点商品行购买。

## 和工厂终端的区别

| | 工厂终端 | 通用终端 |
|---|---|---|
| 公司 | 方块固定一家 | 由卡决定 |
| 等级 | 低/中/高 | 无 |
| 库存/补货 | 有（上限3） | 当前没有 |
| 商品页 | 滚动列表 | 每页 8 个，可翻页 |
| 主要用途 | 公司商店 | 一台机器逛六家 |

## 规则

- 当前公司由卡槽里的第一张有效卡决定；想换公司就换卡；
- 购买要插卡/有账户；
- 声望不足会拒绝；
- 通用终端本身没有工厂等级，所以不按机器等级卡商品；
- 没有库存上限，当前可以重复买；
- 不收购物品；
- 不提供资金转化/转账，去货币银行。

## 注意

- 卡槽里放多张不同公司的卡时，界面只认第一张有效卡；
- 拆掉会掉落方块和卡槽里的卡；
- 价格按当前卡公司的价目表；
- 通用终端不是“模块打印机”，也不是“载具打印机”。
