# 载具打印机（工厂装配核心）

> 方块 ID：`factory_core`  
> 归属：6 家公司各一种  
> 等级：低 / 中 / 高  
> 结构：3×2×2 = 12 格（1 个控制器 + 11 个打印机部件）  
> 作用：用蓝图 + 材料 + 组装费，造完整载具/物理结构

## 一句话

选蓝图 → 投材料 → 插卡 → 选投放点 → 一键组装。  
它打印的是**完整载具或完整物理结构**，不是模块。

## 放置

- 需要 **3×2×2** 的空间和正确朝向；
- 放下控制器后会自动生成 11 个 `printer_part`；
- 空间不够会放不下去；
- 拆掉控制器或任意一个部件，整台机器会一起拆掉；
- 不要手动放置 `printer_part`。

## 打开

- 空手右键可以打开界面看蓝图；
- 插卡后才能付组装费；
- 卡槽在界面左侧。

## 蓝图来源

载具打印机读：

1. 玩家自己的 Sable 蓝图：
   - `Sable-Schematics/`
   - `schematics/`
   - `exnv_aeronautics_structures/`
2. 服务端预制载具：
   - `config/deepspacedeployer/vehicles/*.nbt`

**不读** `config/deepspacedeployer/modules/` 里的模块预设。

## 组装流程

1. 「蓝图」页滚轮选一份蓝图；
2. 看尺寸、方块数、材料清单；
3. 把材料放进投料格（或用创造板条箱模式）；
4. 把银行卡放进卡槽；
5. 需要的话点「选投放点」，在俯视图里点位置；
6. 点「一键组装」；
7. 等组装进度完成，成品直接生成成物理结构。

## 费用和门槛

- 组装费 = **每方块价格 × 蓝图方块数**，默认 20/方块（`factory.assembly_fee_per_block`）；
- 组装费从插卡账户按这台核心所属公司结算；
- 材料另算，从投料格扣；
- 等级限制最大蓝图方块数；
- 等级影响组装时间：
  - 低级默认 20 秒
  - 中级默认 12 秒
  - 高级默认 6 秒
- 声望可能影响可打印的蓝图/商品，以界面提示为准。

## 投放点

- 不选时默认落在玩家面向方向前方 3 格；
- 选点范围默认 96 格（`factory.assembly_max_radius`）；
- 目标区域有方块会拒绝；
- 地图里蓝框是核心，金框是落点。

## 创造板条箱模式

核心附近有机械动力的**创造板条箱**时（默认半径 5 格）：

- 材料无限；
- 不收组装费；
- 立刻放置。

服务器可以通过 `factory.creative_crate_infinite` 关掉。

## 失败和退款

- 材料或钱不够不会开始；
- 生成物理结构失败时，**材料会退回**；
- 组装费按当前实现**不退**，所以选点前先确认场地；
- 如果服务器关了 `factory.assemble_as_physics`，成品会以普通方块形式放下，而不是物理结构。

## 和模块打印机的区别

| | 载具打印机 | 模块打印机 |
|---|---|---|
| 玩家自己的 Sable | 可以 | **不可以** |
| 服务端预制 | `vehicles/` | `modules/` |
| 材料 | 要 | **不要** |
| 费用 | 组装费 + 材料 | 只扣公司货币 |
| 用途 | 完整载具/结构 | 模块化物理结构 |
