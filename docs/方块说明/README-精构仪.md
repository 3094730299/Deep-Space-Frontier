# 精构仪

> 方块 ID：`precision_fabricator`  
> 归属：无  
> 等级：无  
> 结构：1×1×5 装饰性多方块  
> 作用：装饰 / 展示，没有功能界面

## 一句话

一台会播放 5 秒制作动画的装饰性机器。它**不是**模块打印机，也不生产物品。

## 放置

- 放下主体后会自动生成左右共 4 个 `precision_fabricator_part`；
- 需要 1×1×5 的空间；
- 空间不够会放不下去；
- 不要手动放部件。

## 使用

- 没有菜单；
- 没有物品/材料槽；
- 没有配方；
- 放下后自动播放/循环模型动画；
- 纯装饰、工厂造景、拍视频用。

## 拆除

- 拆主体或任意一个部件，整台精构仪会一起拆掉；
- 拆掉掉落主体方块；
- 部件不会单独留下。

## 注意

- 精构仪和“载具打印机”“模块打印机”没有关系；
- 它不会读蓝图，也不会生成物理结构；
- 没有 GeckoLib 时可能显示成普通方块/隐形，属于渲染依赖问题。
