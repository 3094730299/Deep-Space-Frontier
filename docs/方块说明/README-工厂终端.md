# 工厂终端（商店）

> 方块 ID：`factory_terminal`  
> 归属：6 家公司各一种  
> 等级：低 / 中 / 高  
> 作用：按本公司价目表买商品

## 一句话

这是“商店”。插卡、选商品、付钱；商品有独立库存，卖空要等补货。

## 放置

- 放下后归属和等级就固定了，不能在使用中换公司；
- 低级/中级/高级是三个不同物品变体；
- 不需要多方块结构，单格方块。

## 打开

- 空手右键可以打开界面看商品；
- 手持银行卡右键会把卡插进卡槽并尝试开机；
- 购买必须插卡（或有可用账户），只浏览不用卡。

## 购买

1. 在商品列表里滚轮上下翻；
2. 看等级门槛和声望门槛；
3. 点右侧「买」；
4. 钱按支付规则从卡账户结算，商品进背包；背包满会掉在脚边。

## 库存

- **每件商品独立库存，上限 3，初始 3**；
- 买一件扣 1 个；
- 库存 0 时按钮禁用，服务端也会拒绝；
- 补货间隔看方块等级：
  - 低级：**5 分钟**
  - 中级：**3 分钟**
  - 高级：**1 分钟**
- 到点补满到 3；
- 库存按方块保存，拆了再放不会保留；
- 价目表新增商品会自动补 3。

## 价格和门槛

- 价格按公司价目表；
- 商品可以有最低工厂等级、最低声望；
- 声望来自在该公司消费（默认每消费 1000 加 1 点，可配置）；
- 商店**不收购**物品；卖东西去收购投送机。

## 蓝图凭证

终端商品里可能有“蓝图凭证”。买下后：

1. 手持凭证；
2. 右键载具打印机（`factory_core`）；
3. 核心会选中凭证对应的蓝图，凭证消耗。

## 注意

- 拆掉终端会掉落方块本身和卡槽里的卡；库存不随方块带走；
- 购买时如果钱不够，会提示公司余额不足；
- 转账/存取可以直接用货币银行；终端主题如果带“资金转化”按钮，以当前主题为准。
