# 寄售市场

> 方块 ID：`market`  
> 归属：**无归属**  
> 等级：**无等级**  
> 作用：玩家之间挂物品/载具，以币或以物易物

## 一句话

玩家自己的交易行。挂单存在世界存档里，拆方块、换地方都不会丢。

## 放置

- 单格方块，中立设施，不属于任何公司；
- 没有等级；
- 不需要多方块。

## 界面

打开后有两个页：

- **逛市场**：看别人的挂单，买或撤自己的单；
- **我要卖**：挂物品或载具，设置价格/以物易物。

界面里有银行卡槽和三个物品格：

| 格子 | 作用 |
|---|---|
| 待售格 | 挂单时把货搬进挂单存档；挂上去不能直接拿回，只能撤单 |
| 需求格 | 以物易物时想换到的东西；放几个就是要几个 |
| 取货格 | 买到的东西、撤单退回的东西；只出不进 |

## 以币交易

- 买方用**账户余额**付款；
- 每张挂单自己记录收哪家公司的钱；
- 钱直接进卖家账户；
- 当前没有额外的市场手续费（以实际界面为准）；
- 买方和卖方都要有可用账户/卡。

## 以物易物

- 卖家在需求格放要求物品，数量按格子里的数量；
- 买家必须交出同样物品 × 数量；
- 不满足就不能买；
- 成交后货进取货格。

## 挂载具

- 在「我要卖」页切到“卖：载具”；
- 列出可用的 Sable 蓝图（含多物理结构载具）；
- 选一份，挂单；
- 买家买下时直接在市场方块位置生成**物理结构**；
- 生成失败会自动退款，挂单保留。

## 规则

- 挂单存在 `MarketData` 世界存档，整个世界一份；
- 拆掉市场方块不会删挂单；
- 不能买自己的单；
- 撤单只能撤自己的；
- 取货格满了不能买/撤；
- 买家钱不够、物不够会拒绝；
- 市场没有库存/补货概念。

## 注意

- 以币挂单的收款公司是**挂单时选的**，不是市场方块的公司（市场没有公司）；
- 挂载具前确认买家能在这个市场位置放下物理结构；
- 市场没有等级，所以不存在“低级市场不能买高级货”的限制。
