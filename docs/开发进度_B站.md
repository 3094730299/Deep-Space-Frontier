## 开场可用的一段话

> 六家星际公司在世界上建厂、开店、收货，你要在它们之间倒买倒卖，
> 用蓝图把结构造出来，最后让整艘船**成为真正的物理载具**。

## 一、一句话定位

**给机械动力生态加一层"工业经济"** —— 不是加机器，而是回答"你为什么要造这些"。

```
造东西  →  蓝图（机械动力 .nbt 结构）
赚钱    →  收购站 + 寄售市场
花钱    →  六家公司各自的商店
起飞    →  工厂核心直接产出物理结构（Sable / 航空学）
```

## 二、做完了什么（可逐条讲）

### 1. 六家公司（经济系统的骨架）

| 公司 | 定位 |
|---|---|
| 阈限实验集团 | 科研器材，冷白 |
| 低语环带科技 | 电子信号，紫 |
| 断锷军械财团 | 军火，红 |
| 掠影推进公司 | 推进器，橙 |
| 磐基重工工业 | 重工建材，土黄 |
| 星联动力联盟 | 高端能源，天蓝 |

**每家有独立的货币、商品池、收购价、声望**，互不相通。

> 讲解点：**"同一件东西，六家给的钱不一样"** —— 这是整个玩法的发动机。

### 2. 世界生成：18 座工厂

六家公司 × 低/中/高三级。**等级直接决定价钱**：

```
低级厂 0.8×（压价）   中级厂 1.0×   高级厂 1.2×（溢价）
```

> 讲解点：**把货从低级厂拉到高级厂，本身就是一趟值得跑的买卖** —— 距离换利润率。

### 3. 四类机器

| 机器 | 作用 | 亮点 |
|---|---|---|
| **工厂终端（商店）** | 买材料、卖东西、买蓝图使用权 | 等级 + 声望双门槛解锁 |
| **收购站** | 投物品换钱 | **支持漏斗/机械手** → 可做自动化产线 |
| **工厂装配核心** | 选蓝图 → 投材料 → 一键组装 | **俯视图点哪落哪**；组装费 = 每方块 20 余额 |
| **寄售市场** | 玩家之间挂单买卖 | 真正的玩家间交易（挂单记卖家）|

### 4. 钱与卡（三条规则，很多玩家会记错）

1. 钱**按玩家分账**：每个玩家 × 每家公司 = 一个独立余额
2. 消费**先扣方块内余额，再扣卡上余额**（卡是身份凭证）
3. **跨公司要收 20% 手续费**（走资金转化界面）

**主卡 / 副卡**：副卡的余额是**一笔独立的钱**，转账免费、不能取现。

### 5. 进阶系统

- **授权铭牌**：拿对应公司的铭牌右键机器 → **货币、外观、商品池整套换过去**
- **▽机械级别升级插件**：提升机械级别，配合声望买高档货
- **工厂核心 → 物理结构**：造出来直接能飞（Sable / 航空学）

### 6. 通用终端（这一期的新东西）

一台**会动**的装饰方块 + **多公司交易终端**：

```
放下时：主体升起、四爪张开（0.75 秒动画）
交互  ：内置 6 个卡槽 = 6 家公司
        插入哪家的银行卡 → 变成哪家的商店（一台上切换六家）
```

### 7. 服主工具

- **游戏内价目表编辑器**（ESC 菜单，OP 可见）：可视化改价、改等级、改声望门槛，存进世界数据包
- 商品与收购价**全在数据包里** → 整合包作者可以整套重写
- 游戏内说明书：`/dsd guide card｜buy｜factory`

## 三、技术上的"硬活"（适合展开讲的部分）

### 1. 建模管道：从 Blockbench 到游戏里

这次做通用终端，**踩了 9 个坑才跑通**，最后固化成一套流程：

```
老板在 Blockbench 导出三个文件
    geo.json（几何 + 骨骼）
    animation.json（关键帧动画）
    png（贴图）
        ↓  模组里只做"搬运"，不做转换
GeckoLib 渲染（模型 + 动画都是官方产物）
```

**为什么不用自己转换？** 试过 —— bbmodel 内部用四元数存旋转，转成欧拉角时
**符号会翻**，结果两只爪子转向相反。**官方的文件直接用，才不会出错。**

### 2. 反向工程：怎么读别人的模组

为了做细碰撞箱，我**反汇编了另一个模组**（impact_drill）的 `HullCoreBlock`：

```
它的做法：多个盒子 Shapes.or 合并 + 按 4 个朝向预烘焙成数组，运行时查表
我照这个思路 + 从建模几何逐层算盒子 → 碰撞箱贴合模型轮廓
```

> 讲解点：**碰撞箱不是一个盒子** —— 托盘比柱身宽、底盘比柱身深，
> 走过去不会被空气挡住。

### 3. 遇到的硬问题（都可当"故事"讲）

| 问题 | 真相 |
|---|---|
| 模型显示但完全没动画 | **几何文件的格式版本**不被 GeckoLib 支持，被**静默拒绝加载** —— 日志里只有一行警告 |
| 贴图变成粉绿色块 | 我"好心"改了贴图尺寸声明 —— 但那不是像素尺寸，是 **UV 坐标系** |
| 模型跑到方块边角 | 渲染器里自己加了一次平移 —— 而 GeckoLib 内部**已经加过了**，偏移翻倍 |
| 动画永远定格 | 控制器写法不对：**"每帧返回动画"** 和 **"触发式播放"** 语义完全不同 |

### 4. 数据驱动的验证流程

每改一次都跑：

```
构建 → 自动校验（validate.py）→ 装机核对哈希 → 扫日志里的报错
```

`validate.py` 会检查：方块状态、模型、贴图、语言文件、战利品表、工具标签、
结构、世界生成，还有**元素旋转角度是否合法**。
